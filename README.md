# 硬件性能天梯榜

桌面端 & 移动端的显卡与处理器综合性能天梯排名，收录 **1568 款**硬件（显卡 421 · 处理器 1147），
覆盖 2008 年至今。

## 访问

纯静态站点，零依赖、无构建步骤。直接用浏览器打开 `index.html`，
或通过任意静态服务器访问（GitHub Pages / Nginx / `python -m http.server`）。

## 数据

| 象限 | 数量 |
|---|---|
| 显卡 · 桌面端 | 164 |
| 显卡 · 移动端 | 257 |
| 处理器 · 桌面端 | 548 |
| 处理器 · 移动端 | 599 |

品牌覆盖：AMD 520 · Intel 1010 · NVIDIA 171 · Apple 36 · Qualcomm 12。

## 指标口径

- **显卡光栅性能** — 3DMark Time Spy Graphics（显卡分）
- **显卡光追性能** — 3DMark Port Royal（无原生成绩者按"无成绩"处理）
- **处理器多核 / 单核** — Cinebench R23 Multi / Single Core
- **处理器游戏性能** — 相对指数，以桌面 Ryzen 7 9800X3D = 100 为基准

桌面端与移动端**共用同一评分量纲**，可直接横向比较。
型号清单参考了第三方天梯站的收录范围，分数统一换算到上述基准——
部分型号（尤其笔记本显卡、低压 U/Y 系列、HEDT 平台与 2019 年前的型号）为换算估值，
仅用于横向性能对比，不作为精确规格依据。

## 功能

- 桌面端 / 移动端 / 全部 三视图切换
- 多指标切换：光栅 / 光追（显卡）、多核 / 单核 / 游戏（处理器）
- 品牌、发布年代、显卡类型（独显 / 核显）筛选
- 关键词搜索 + 四种排序
- 天梯图与表格双视图，天梯按性能档位分组
- 行内展开完整规格参数
- 最多 4 款型号横向对比（含相对条形图与最优项高亮）
- URL 哈希路由，如 `#gpu/mobile/raster/ladder`，可分享

## 文件结构

```
index.html          页面骨架
css/style.css       样式
js/meta.js          指标定义与数据版本
js/gpu-desktop*.js  桌面端显卡（3 个文件）
js/gpu-mobile*.js   移动端显卡（3 个文件）
js/cpu-desktop*.js  桌面端处理器（3 个文件）
js/cpu-mobile*.js   移动端处理器（6 个文件）
js/app.js           交互逻辑
```

数据按象限拆成多个模块文件，扩充型号只需在对应分类追加数组。
