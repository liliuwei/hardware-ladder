收录范围：2008 年至今，分桌面端与移动端两套天梯，共 1560+ 款（显卡 421 · 处理器 1147）。 显卡覆盖 NVIDIA GTX 400 → RTX 50、AMD HD 7000 → RX 9000、Intel HD/Iris/UHD/Arc 全系及 Apple M 系列； 处理器覆盖 Intel 凌动/Core 2 → 酷睿 Ultra 200 / Panther Lake、AMD Phenom II → 锐龙 9000 与 Threadripper、 Apple M1 → M6、高通骁龙 X / X2，含各代 U / Y / H / HX / MQ / HQ / QM 全后缀。
数据说明：显卡光栅性能取自 3DMark Time Spy Graphics（显卡分），光追性能取自 3DMark Port Royal； 处理器多核 / 单核性能取自 Cinebench R23，游戏性能为以桌面 Ryzen 7 9800X3D = 100 为基准的相对指数。 型号清单参考了第三方天梯站（PassMark / Notebookcheck / nanoreview 口径）的收录范围，分数统一换算到上述基准 —— 因此部分型号（尤其笔记本显卡、低压 U/Y 系列、凌动与 Bay Trail 核显、HEDT 平台及 2019 年前的型号）为换算估值， 同型号会因频率、功耗墙、驱动版本与散热条件产生浮动，仅用于横向性能对比，不作为精确规格依据。
注意：桌面端与移动端共用同一评分量纲，因此可以直接横向比较（例如移动端旗舰约相当于桌面端中高端）； 但移动端性能受笔记本模具的功耗与散热释放影响极大，同芯片不同机型差异可达 30% 以上 —— 低压 U 系列尤其明显。 2016 年以前的老硬件在老平台上受瓶颈限制，此处取上限估计值。 Apple / 高通平台无 3DMark Port Royal 原生成绩，光追一栏按"无成绩"处理。
提示：天梯排名是性能参照系，不代表选购建议——还需结合分辨率、显存容量、功耗与价格综合判断。 跨代对比时请注意：显存容量、驱动支持周期与新技术特性（如 DLSS / FSR / 光追）的差距，往往比跑分差距影响更大。
